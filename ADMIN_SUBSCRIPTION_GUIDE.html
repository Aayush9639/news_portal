💎 Admin Subscription Management Guide

✅ System Ready: Your subscription management system is fully configured and ready for admin control!

📍 Access Points

Quick Access

Admin users can access subscription management from:

  • Sidebar Link: Click "💎 Subscriptions" in the admin panel sidebar
  • Dashboard: View subscription statistics on admin dashboard
  • Direct URL: /admin/subscriptions/

🎯 Main Features

1. Manage Subscription Plans

URL: /admin/subscriptions/subscriptionplan/

What you can do:

  • ✅ Create new subscription plans (Free, Basic, Premium, Custom)
  • ✅ Edit existing plans (name, price, features)
  • ✅ Set plan type (free/basic/premium)
  • ✅ Define features (comma-separated)
  • ✅ Set prices in Indian Rupees (₹)
  • ✅ Add Stripe Price ID for payment integration
  • ✅ Activate/Deactivate plans with one click
  • ✅ View creation date and plan status

2. Monitor User Subscriptions

URL: /admin/subscriptions/usersubscription/

What you can do:

  • ✅ View all users with active subscriptions
  • ✅ Check subscription status (pending/completed/failed/cancelled)
  • ✅ See subscription expiry dates
  • ✅ Filter by plan type
  • ✅ Search users by username or email
  • ✅ Track last payment date
  • ✅ View Stripe customer and subscription IDs

3. Review Payment Transactions

URL: /admin/subscriptions/payment/

What you can do:

  • ✅ View all payment transactions
  • ✅ Check payment status (pending/completed/failed/refunded)
  • ✅ See payment amounts in INR
  • ✅ Filter by payment method (Stripe)
  • ✅ Filter by currency (INR)
  • ✅ Search by transaction ID
  • ✅ Search by user email
  • ✅ View payment dates
  • ✅ Track Stripe payment intent IDs

⚙️ Plan Configuration

Field Description Example
Plan Name Display name for the plan Monthly Plan, Yearly Plan, Premium Access
Plan Type Category (free/basic/premium) Select from dropdown
Price Amount in Indian Rupees 499, 4999, 9999
Description Short description shown to users Unlimited access for full month
Features Comma-separated list of features Unlimited articles, Ad-free, Exclusive content
Is Active Show/hide plan from users ☑ Checked = Visible to users
Stripe Price ID ID from Stripe dashboard (optional) price_1234567890
💡 Tip: When adding features, use comma separation like:
Unlimited article access, Ad-free reading, Exclusive content, Email newsletter, Save articles

🎓 Common Tasks

Task 1: Create a New Plan

  1. Go to /admin/subscriptions/subscriptionplan/
  2. Click "ADD SUBSCRIPTION PLAN" button
  3. Fill in the details:
    • Name: e.g., "Student Plan"
    • Type: Select "basic" or "premium"
    • Price: Enter in ₹, e.g., 299
    • Description: e.g., "Special plan for students"
    • Features: "Limited articles, Weekly newsletter"
  4. Click "SAVE"
  5. Plan is now visible to users on subscription page!

Task 2: Update Plan Price

  1. Go to /admin/subscriptions/subscriptionplan/
  2. Click on the plan name you want to edit
  3. Change the price in the Pricing section
  4. Click "SAVE"
  5. Price is updated immediately for new subscriptions!

Task 3: Disable a Plan

  1. Go to /admin/subscriptions/subscriptionplan/
  2. Uncheck the "Is Active" checkbox next to the plan
  3. Click "SAVE"
  4. Plan will no longer appear on subscription page
  5. Existing subscribers continue with their subscriptions

Task 4: View Payment History

  1. Go to /admin/subscriptions/payment/
  2. Use filters on the right side:
    • Filter by Payment Status (completed, failed, etc.)
    • Filter by Date Range
    • Filter by Currency (INR)
  3. Use search to find payments by user email or transaction ID
  4. Click on any payment to see full details

❓ FAQ

Q: Can I manually create subscriptions for users?

A: No, subscriptions can only be created through the payment checkout process. This prevents fraud and ensures payments are processed correctly.

Q: Can I change prices for active subscriptions?

A: Yes! New subscriptions will use the new price. Existing subscriptions keep their original price until renewal.

Q: How do I refund a payment?

A: Refunds must be processed through Stripe dashboard. Go to Stripe account → Payments → Select transaction → Refund. The status will update in the admin panel.

Q: Can I see Stripe customer details?

A: Yes! Go to User Subscriptions and click on a subscription to see Stripe Customer ID and Subscription ID for that user.
